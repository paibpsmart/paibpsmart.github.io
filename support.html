Pusat Bantuan

Dukungan Pengguna

Panduan ringkas untuk penggunaan PAIBP SMART SMP.

🛠️

Masalah teknis

Muat ulang halaman, periksa ruang penyimpanan browser, dan gunakan versi terbaru Chrome, Edge, Firefox, atau Safari.

📴

Mode offline

Halaman inti, jawaban, dan rekap lokal tetap tersedia tanpa login. Surat Al Qur'an dan audio perlu dibuka/disimpan sekali saat tersambung internet.

📤

Kirim dan rekap tugas

Murid membagikan berkas Word .docx. Guru mengimpornya melalui Ruang Guru → Rekap Pekerjaan Murid, lalu dapat mengunduh rekap Word atau menyimpan PDF.

Pertanyaan yang sering diajukan

Apakah aplikasi memerlukan akun?

Murid tidak memerlukan akun. Ruang Guru memakai kata sandi sesi untuk membatasi akses menu guru pada perangkat yang sedang digunakan.

Apakah aplikasi menampilkan iklan?

Tidak. Versi 1.0 dirancang tanpa iklan dan tanpa ID iklan.

Bagaimana menghapus progres?

Gunakan tombol hapus progres pada Fitur Games. Untuk menghapus seluruh jawaban, rekap, audio, dan data lokal, buka pengaturan data situs pada browser.

Mengapa tugas tidak langsung masuk ke akun guru?

Situs GitHub Pages tidak memakai server akun. Agar identitas murid tidak disimpan pada server publik, tombol kirim membuat berkas tugas privat. Murid mengirim berkas itu melalui kanal kelas, kemudian guru mengimpornya.

Bagaimana guru membuat rekap?

Buka Ruang Guru → Rekap Pekerjaan Murid → pilih seluruh berkas .docx. Isi nilai dan catatan, lalu gunakan Unduh Rekap Word, Cadangkan Jawaban Word, atau Cetak / Simpan PDF.

Mengapa Rekap Akses Murid tertulis belum diaktifkan?

Rekap lintas perangkat memerlukan Google Apps Script. Pengelola perlu mengikuti PANDUAN_REKAP_REALTIME.md dan mengisi URL Web App pada app-config.js. Tanpa langkah itu, website sengaja tetap memakai mode lokal.

Bagaimana audio Al Qur'an diputar saat luring?

Buka surat ketika online, lalu pilih “Simpan audio luring” dan tunggu seluruh ayat selesai. Audio tersimpan hanya pada browser/perangkat tersebut.

Apakah aplikasi menggantikan buku dan guru?

Tidak. Aplikasi adalah media pendukung. Guru dan sumber resmi tetap menjadi rujukan utama.

Bagaimana melaporkan masalah?

Buka halaman Kontak dan kirimkan email melalui alamat dukungan resmi.
